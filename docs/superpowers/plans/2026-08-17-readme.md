在对应章节明确写入：

```text
GetAllProjectItem.js：只遍历项目根目录的直接子项，进入名为 base_V3 的素材箱，查找区界.wav，并将已验证代码中的硬编码数值 10 作为 Track.overwriteClip 的时间参数传入 A1；文档只记录现有行为，不修改或重新解释代码。
PrintBgmStartTime.js：当前入口调用 printBgmStartTime(1)，读取零基索引 1，也就是 A2，并将剪辑名称和起始秒数写入 ExtendScript 控制台。
PlaceMarkerSegments.js：把从 0 到每个序列标记点的连续区间作为分段；递归查找 GLT_P0_<序号>_BASE/MASK 唯一素材，分别覆盖写入 V5/V6，并将剪辑结束点设置为区间终点。
```

- [ ] **Step 4: 写入安全提示和失败条件**
